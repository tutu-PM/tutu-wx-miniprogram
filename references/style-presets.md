# 风格套餐

**套餐是参考，不是题库。** 下面四套把常见产品的视觉决定配好了，可以照抄一套、改几项、或者完全按产品气质重新配一套——**关键不在选中第几个，而在最后能不能写出四项确定的值**：配色、圆角与阴影、图片策略、动效强度。

一个产品只一套，不能这页暖食、那页卡通。

风格不是形容词（"简洁""高级"都不算），是**一组具体决定**。套餐的作用是省掉从零想这四项的成本，也顺便给出"哪些做法容易翻车"。

---

## 怎么选（也可以不选）

看**产品在面对谁、要什么情绪**，不看行业名字：

| 如果产品的核心感受是 | 可以参考 |
|---|---|
| 温暖、生活、有食欲、家常 | **暖食生活** |
| 干净、高效、不打扰、办事 | **清爽简洁** |
| 有趣、轻松、陪伴、养成 | **卡通圆润** |
| 严谨、数据、可靠、效率 | **专业工具** |

**表里没有你的感觉，就不用硬套。** 情绪对不上时，按"四项取值"自己配：主色一个、中性灰阶一套、圆角两档、图片策略一句话、动效强度一句话。写死这四项就是合格的自定义风格；写不出，才回到表里挑一个最近的当起点。

**风险提示（选之前先看）：**

- **卡通圆润是最容易翻车的**：它需要一整套风格统一的插画/角色。没有画师、也没法稳定生成同一画风时，选它必成"四不像"。**没有成套素材能力，就不要选卡通。**
- **暖食生活依赖真实照片**：没有实拍图，它退化成"暖色白板"，比清爽简洁更难看。
- **清爽简洁最安全**：几乎不需要素材，靠排版和留白撑。

## 套餐一：暖食生活

**适合**：菜谱、餐饮、家庭、生活方式
**一句话**：像一张摆好的饭桌——暖、有实物、不花哨。

| 项 | 决定 |
|---|---|
| 主色 | 暖橙 / 陶土棕，如 `#C8754A` |
| 底色 | 米白 `#FFFCF8`；卡片纯白 |
| 文字 | 主 `#241D19`、次 `#6F5D53`、辅 `#A3968C` |
| 圆角 | 偏大：小元件 16rpx、卡片 32rpx |
| 阴影 | 极柔：`0 6rpx 20rpx rgba(120,80,50,.08)` |
| 图片 | **必须**。食物、餐桌必须有实拍图；这是主视觉，不是装饰 |
| 字体 | 无衬线，中粗标题（600），正文常规 |
| 动效 | 轻。只做按压反馈，不做花活 |
| 禁忌 | 高饱和撞色、纯色大色块占满首屏、玻璃拟态 |

**判断是否做到位**：把首页截图缩到手机大小，还看得出"这里有吃的"吗？看不出就是没图或图太小。

---

## 套餐二：清爽简洁

**适合**：工具、记账、清单、预约、设置
**一句话**：白底、一个强调色、信息自己说话。

| 项 | 决定 |
|---|---|
| 主色 | 一个冷色（蓝/青/墨绿），只用在按钮和选中态 |
| 底色 | `#F7F7F7` 页面、`#FFFFFF` 卡片 |
| 文字 | `#1A1A1A` / `#666` / `#999` |
| 圆角 | 克制：12rpx / 16rpx |
| 阴影 | 几乎不用；靠留白和 1px 分隔线分组 |
| 图片 | **尽量不用**。靠排版、图标、数字层级 |
| 字体 | 无衬线，字重最多两档 |
| 动效 | 极短：90–120ms，只有透明度或轻微位移 |
| 禁忌 | 大色块、渐变、装饰性插画、每张卡都加阴影 |

**判断是否做到位**：把颜色全去掉（转灰度），页面还清楚吗？清楚就对了。

---

## 套餐三：卡通圆润

**适合**：儿童、养成、社区、轻游戏化
**一句话**：圆、亮、有角色、按下去会弹。

| 项 | 决定 |
|---|---|
| 主色 | 明亮饱和，可配 2–3 个辅色，但**每个色有固定用途** |
| 底色 | 浅奶油或浅蓝，不要纯白 |
| 圆角 | 很大：32–48rpx，按钮可以做成胶囊 |
| 阴影 | 可以有"贴纸感"的硬投影（offset 大、模糊小） |
| 图片 | **成套插画**，统一画风、线宽、光向。角色、道具、状态图要成系列 |
| 字体 | 可用圆体；标题字重明显高于正文 |
| 动效 | 允许回弹和小幅过冲（scale 到 1.05 再回 1.0），200–300ms |
| 禁忌 | 插画风格不统一、真人照片+卡通混用、四种以上高饱和色同屏 |

**判断是否做到位**：把两个不同页面的插画并排，看得出是同一套画的吗？看不出就是没成套。

---

## 套餐四：专业工具

**适合**：数据、后台、管理、工作流
**一句话**：信息密度高，但每一层都对齐得死死的。

| 项 | 决定 |
|---|---|
| 主色 | 深蓝 / 深绿，克制使用，只标动作和选中 |
| 底色 | 白 + 浅灰分区 |
| 文字 | 三档灰，字号最多四档，数字用等宽 |
| 圆角 | 小：8rpx / 12rpx |
| 阴影 | 不用，用 1px 边框和底色分区 |
| 图片 | 只用必要的对象缩略图，不做气氛图 |
| 字体 | 系统无衬线，字重最多两档 |
| 动效 | 几乎不做；只保留状态变化和高亮 |
| 禁忌 | 装饰性大图、过大的标题、卡片套卡片 |

**判断是否做到位**：扫一眼能不能找到"当前在哪、下一步点哪"？找不到就是层级没做出来。

## 定了之后要做什么

1. **把最终取值抄进 `02视觉风格/design-spec.md`**（模板见 `design-spec.md`），再写进全局样式——改一个地方，全项目生效。照抄套餐就抄套餐的值，自己配就写自己配的四项，**规范里不许只写"自定义"三个字**
2. **把这一刻的"禁忌"当检查清单**，交付前逐条对
3. **先用 1 版 HTML 稿看风格，再做 1 个真代码样板页**（见 `design-spec.md` 第十节与 `html-prototype.md`），确认风格对了再铺其他页面——这是防返工最有效的一步

---

## 不要做的事

- **不要把互相矛盾的做法拼在一起**：暖食的圆角 + 专业的配色 + 卡通的插画 = 哪个都不像
- **不要在产品中途换风格**：换一套等于全项目重做，成本极高
- **不要用形容词代替取值**：说"要高级""要更有质感"时，先把它翻译成主色、灰阶、圆角、图片策略上的具体改动
